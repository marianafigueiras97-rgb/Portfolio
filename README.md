# Personal Portfolio

This repository contains my personal developer portfolio, created to showcase my projects, technical skills, and learning journey as a Software Development student.

The website serves as a central place where recruiters and collaborators can explore my work, learn about my background, and access my featured projects.

## Features

- Responsive design for desktop and mobile devices
- Clean and modern user interface
- Smooth animations and interactive elements
- Project showcase with links to repositories
- Contact section

## Skills Demonstrated

- HTML5 semantic structure
- CSS3 (Flexbox, Grid, animations, responsive design)
- JavaScript (DOM manipulation and interactivity)
- UI/UX design principles
- Git & GitHub workflow

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Purpose

The goal of this project is to demonstrate front-end development fundamentals, clean code organization, and the ability to build and deploy a complete responsive website.
